## List of Practicals

1. **Practical 1: Depth First Search (DFS)** - `Prac_1_DFS.py`
2. **Practical 2: Breadth First Search (BFS)** - `Prac2_bfs.py`
3. **Practical 3: Water Jug Problem (State-Space Search via BFS)** - `Prac3_water_jug.py`
4. **Practical 4: N-Queens Problem (Backtracking)** - `Prac4_nqueen.py`
5. **Practical 5: Minimax Algorithm (Tic-Tac-Toe AI)** - `Prac5_minimax.py`
6. **Practical 6A: Perceptron Neural Network (Without Library)** - `Prac6A_neuralnetwork_without_library.py`
7. **Practical 6B: Neural Network with Library (Scikit-Learn)** - `Prac6B_neural_network_with_lib.py`
8. **Practical 7: Greedy Best-First Search (GBFS)** - `Prac7_greedy_bfs.py`
9. **Practical 8: A* Search Algorithm** - `Prac8_A_star.py`
10. **Practical 9: AIML Chatbot** - `Prac9_aiml_chatbot.py`
